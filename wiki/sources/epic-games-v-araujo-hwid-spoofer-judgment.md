## Narrative

Default judgment: defendant used a **DMA** cheat device in Fortnite tournaments and, after hardware-ID bans, **hardware ID spoofers** to alter device serial appearance. Epic pled anti-cheat software **and** hardware-ID bans as DMCA §1201 technological measures. Court granted default judgment; damages **$175,521**; injunction covers circumventing Epic’s technological measures and using unauthorized competitive-advantage devices. [CONFIRMED docket + order + memo]

Steal for this wiki: in a US publisher’s framing, a HWID spoofer used to defeat a ban is **circumvention**, not a research tool. Lab/product work on **your** license or AC stays in scope; “unban this Fortnite box” does not.
