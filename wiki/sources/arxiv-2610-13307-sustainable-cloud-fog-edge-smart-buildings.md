## Narrative

**K420 — OOD (sustainability / embedded ML).** An architecture and algorithmic study for **privacy-preserving, low-power learning inside smart buildings**: an Arduino sensor chain (Uno R4 WiFi / BME280), a lightweight **KOptim** SLA orchestrator interoperable with FIWARE, and a **Generalized Hebbian Algorithm (GHA) PCA** adapted to run on microcontrollers under a memory constraint, using buffered sorting that preserves extreme samples. It roughly matches full-memory PCA quality at **O(W log W)** sorting cost and includes a **critical review of fog-node security vulnerabilities and power overhead**. Repo `github.com/madou-sow/OnlineML_ESP32`; licence not stated. **Not security-primary** — no attack or defense technique for this wiki's lanes; retained as a stub for the edge/IoT footprint.
