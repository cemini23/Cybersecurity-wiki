## Narrative

Predictive memory layer for agentic coding: estimates prompt **blast radius** on (1) context retention and (2) churn-weighted code reach; **NECROPHORESIS** archives dead message bodies byte-exact to a midden (SQLite) and leaves scent skeletons; **RDM** buries recurring build/test/VCS transcripts via Laplace succession. Layers under HCRC gate (verification licenses *whether* to compact; Blast Radius scopes *what/how far*). Eval across seven OpenAI models: Blast Radius + RDM cut tokens **17–26%**, lowest overflow, **0/450** exhumations. [CONFIRMED from paper tables]
