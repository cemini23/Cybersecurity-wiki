## Narrative

Debian-based Linux distribution purpose-built for penetration testing, security research, and digital forensics. Maintained by Offensive Security, it ships with 600+ pre-installed security tools covering reconnaissance, vulnerability analysis, exploitation, post-exploitation, forensics, and reporting. Standard platform for OSCP, OSWA, OSWE, and most hands-on security certifications. Key tool categories: information gathering (Nmap, Maltego), vulnerability analysis (Nikto, OpenVAS), web application (Burp Suite, sqlmap, OWASP ZAP), password attacks (Hashcat, John, Hydra), wireless (aircrack-ng, Reaver), exploitation (Metasploit, searchsploit), post-exploitation (Empire, BloodHound).
