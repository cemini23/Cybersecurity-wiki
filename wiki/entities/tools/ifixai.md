## Narrative

**Verdict: Adopt as diagnostic harness.** Apache-2.0; ~1.1k★; tagged releases and CI. iFixAi runs inspections against agent outputs for manipulation, deception, opacity, sabotage, sandbagging, and related frontier-risk patterns.

Use it as an evidence-producing gate for agent output, not a security or legal certification. Main risks are judge reliability, latency/cost, self-judge bias, and overbroad compliance interpretation.
