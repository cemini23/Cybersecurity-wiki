## Narrative

Incident Response = the structured process for detecting → containing → eradicating → recovering from → learning from a security incident. NIST SP 800-61r2 is the canonical lifecycle (Preparation / Detection & Analysis / Containment, Eradication & Recovery / Post-Incident Activity). SANS uses the PICERL model (Preparation, Identification, Containment, Eradication, Recovery, Lessons Learned). The corpus's *Incident Response Simulation 1.pdf* is a hands-on tabletop exercise.
