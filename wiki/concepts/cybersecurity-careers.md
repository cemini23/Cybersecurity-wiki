## Raw Concept

30+ corpus PDFs explicitly scope into career / education / certification roadmaps — the largest single sub-collection alongside Red Team Ops.

## Narrative

Cybersecurity careers split coarsely into Red (offensive — pentest / red team / bug bounty / exploit-dev), Blue (defensive — SOC / IR / threat hunting / detection engineering), Purple (both), GRC (governance / risk / compliance), and adjacent (DevSecOps, AppSec, cloud security engineering, security architect). The *INFOSEC PROEFICIENCY COLORS.pdf* covers the color taxonomy. Typical entry paths: Tier-1 SOC analyst → Tier-2 SOC → IR → threat hunting (Blue lane); IT helpdesk → junior pentester → mid pentester → red team operator (Red lane). The corpus's strongest theme is **career mapping for Brazilian + Latin-American context** (employer expectations, R$-denominated salary baselines, local cert acceptance). See @entities/certifications/* for the cert ladder.
