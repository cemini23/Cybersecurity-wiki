## Narrative

Cybersecurity careers split into a **color taxonomy** widely cited in the corpus and broader community: [Source: INFOSEC PROEFICIENCY COLORS.pdf]

### The color wheel (Joas's HXH-Nen-inspired chart)

- **RED TEAM** — offensive security tactics. Skills: programming/automation 50%, offensive security 100%, adversary emulation 100%, vulnerability management + testing controls 100%, DevSecOps 50%. Raises the maturity of internal processes by stress-testing them.
- **BLUE TEAM** — defensive security tactics. Skills: incident response + security controls 100%, automation + forensics 80%, threat hunting + adversary emulation 60%, AppSec 50%, offensive security 80%. Improves and increases process maturity by detecting + responding to threats.
- **PURPLE TEAM** — combines red + blue. Skills: automation testing 50%, adversary emulation 100%, threat hunting 80%, offensive-security campaign 100%, facilitates threat detection.
- **YELLOW TEAM** — systems architecture, software engineering, DevOps. Skills: secure by design 50%, automation 100%, security controls 70%, AppSec 70%, security testing 50%, compliance + risk management 50%. The *builders* — security-aware engineers.
- **GREEN TEAM** — yellow ∩ blue. Skills: automation + programming 80%, detection of threats 80%, DevSecOps 60%, governance 60%, security testing/process success measurement 40%, pentest 50%. Focuses on automating defensive operations.
- **WHITE TEAM** — governance, risk, and compliance (GRC). Coordinates exercises, sets policy, measures success. Skills: improve process maturity 70%, security controls 60%, AppSec 40%, security testing 70%, compliance 100%.
- **ORANGE TEAM** *(not always included)* — yellow ∩ red. Builders working with offensive security to embed security into development workflows.

### Lane → role mapping

| Lane | Typical entry role | Mid | Senior |
|------|--------------------|-----|--------|
| Red | Junior pentester | Pentester / red team operator | Red team lead / principal consultant |
| Blue | Tier-1 SOC analyst | Tier-2 / IR analyst | Threat hunter / detection engineer / IR principal |
| Purple | (typically lateral move from Red or Blue) | Purple-team engineer | Adversary emulation lead |
| Yellow / Green | Software engineer + security training | DevSecOps engineer / security engineer | Security architect / staff security engineer |
| White | GRC analyst | Security PM / risk lead | CISO / Director of Security |

### Common entry paths

- **Tier-1 SOC → Tier-2 SOC → IR → threat hunting** (Blue lane)
- **IT helpdesk → junior pentester → mid pentester → red team operator** (Red lane)
- **Software engineer → DevSecOps engineer → security architect** (Yellow / Green lane)
- **Compliance analyst → security manager → CISO** (White lane)

### Brazilian + Latin-American context

The corpus's strongest theme is career mapping for Brazilian + Latin-American operators — employer expectations, R$-denominated salary baselines, local cert acceptance (CEH + Security+ are widely recognized; OSCP signals specialty; eLearnSecurity / INE certs are well-regarded for the cost-to-rigor ratio in BRL terms). The corpus's many *Carreira em…* PDFs cover this in detail.

### Cert ladder by lane

- **Red lane**: CompTIA Security+ → CEH → CompTIA PenTest+ → OSCP → OSWE/OSWA/OSED/OSEP → CRTO / CRTO II → OSEE. See @entities/certifications/oscp.md, @entities/certifications/crto.md.
- **Blue lane**: CompTIA Security+ → CompTIA CySA+ → BTL1 → GCIH / GCFA / GNFA (SANS family) → CISSP for senior management track
- **Cloud-specialty**: AWS Security Specialty / AZ-500 / Google PCSE → CCSP (vendor-neutral)
- **GRC lane**: CISA → CISM → CRISC → CISSP → CISO certifications (CCISO, etc.)
