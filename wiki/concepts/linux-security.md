## Narrative

Linux system security hardening and defense. Covers kernel hardening (SELinux, AppArmor, seccomp), filesystem security (mount options, ACLs, immutability), network defense (iptables/nftables, fail2ban, SSH hardening), logging and auditing (auditd, syslog, osquery), and compliance frameworks (CIS Benchmarks, STIGs). Linux dominates server/cloud/container infrastructure — securing it is foundational to defensive operations.
